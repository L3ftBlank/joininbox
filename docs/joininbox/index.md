## What is JoininBox?

JoininBox is a minimalistic, security-focused Linux environment for **JoinMarket** with a terminal-based graphical menu interface. It provides an accessible way to use JoinMarket's coinjoin technology for Bitcoin privacy.

**JoininBox is NOT JoinMarket** – it's a user-friendly wrapper around the JoinMarket clientserver software.

---

## Why JoininBox?

JoinMarket is powerful but complex. JoininBox simplifies the experience by providing:

- **Terminal-based menu system** - Navigate JoinMarket features without memorizing commands
- **Pre-configured environment** - All dependencies installed and optimized
- **Security-focused design** - Built for running on dedicated hardware like RaspiBlitz
- **Automated setup** - Quick deployment for both beginners and advanced users
